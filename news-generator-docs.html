Problem it solves

Most news is filtered through a single political lens

Traditional news consumption means choosing a channel - and inheriting its bias. Watching only CNN or only Fox News gives you the same day's events framed entirely from one perspective. Checking multiple outlets manually takes too much time.

News Generator solves this by pulling from both left-leaning and right-leaning outlets simultaneously, letting an AI synthesize the reporting into a single balanced broadcast - delivered as a ready-to-watch video every morning before you start your day.

⚖️
Built-in political balance
The source list deliberately pairs opposing outlets: CNN alongside Fox News, NY Times alongside NY Post, ABC News alongside The Daily Wire. The AI anchor synthesizes all perspectives - not just one.
Pipeline at a glance
Phase 1
Collection
Fetches RSS feeds from 24 outlets across 5 categories. Top 15 headlines extracted per source.
Phase 2
AI curation
AI selects the top 5 stories per outlet with a 3-paragraph summary of each, filtered by category rules.
Phase 3
Script writing
A second AI agent writes a 1,600+ word broadcast script with an intro, deep dives, NYC local segment, and sign-off.
Phase 4
Audio & video
OpenAI TTS converts the script to speech. FFmpeg stitches audio to a static background image to produce an MP4.
Phase 5
YouTube upload
The finished video is auto-uploaded to YouTube as unlisted with an AI-generated title and formatted description.
Step-by-step flow
1
Schedule Trigger
Fires every day at 8:45 AM automatically. The entire pipeline runs without any manual action.
n8n Schedule
2
Background image prep
Downloads the branded news background image and saves it to the server's temp folder at /tmp/background.jpg. Old temp files from the previous run are cleared.
HTTP Request File Write
3
RSS source config
A code node defines all 24 news sources with their category tags and Google News RSS URLs, each scoped to articles from the last 24 hours only.
n8n Code Node
4
Loop: fetch one source at a time
A loop node processes each source individually - reading its RSS feed, waiting between requests to avoid rate limits, then formatting the top 15 headlines with titles and links.
n8n Loop RSS Reader
5
AI story selection - top 5 per source
An AI agent (Google Gemini, Claude fallback) reads the 15 headlines per outlet and selects the 5 most newsworthy stories based on strict category rules. Each selected story gets a 3-paragraph TLDR summary.
Google Gemini Claude Sonnet 4.5 (fallback)
6
Story organizer
All curated stories from across every source are grouped by category (National, International, Finance, Tech, Politics, Local) into a single data object ready for the script writer.
n8n Code Node
7
AI script generator - "News" anchor
A second AI agent receives all categorized stories and writes a full broadcast script - 1,600+ words - in the voice of a professional news anchor. Output includes the broadcast script, a YouTube video title, and a formatted video description with source citations. Each broadcast opens and closes with a unique, non-repeated line.
Google Gemini Claude Sonnet 4.5 (fallback)
8
Text chunker
The script is split into 4,000-character chunks at natural word boundaries. This ensures compatibility with TTS API limits without cutting words mid-sentence.
n8n Code Node
9
Text-to-speech (OpenAI TTS, "echo" voice)
Each text chunk is converted to an MP3 audio file using OpenAI's TTS API with the "echo" voice - a deep, authoritative broadcast voice. Each part is saved as /tmp/audio_part_N.mp3.
OpenAI TTS
10
FFmpeg video assembly
A bash command runs FFmpeg directly on the server to stitch all MP3 parts into one audio file, then render the final MP4 by combining the background image with the full audio track. Pixel dimensions are auto-corrected to even numbers for YouTube compatibility.
FFmpeg Bash
11
YouTube upload (unlisted)
The finished MP4 is uploaded to YouTube as an unlisted video in the News & Politics category, with the AI-generated title and description automatically applied. The description includes all source citations and an AI disclaimer.
YouTube API

AI model setup - dual model with fallback
Primary model
Google Gemini
Used for both story selection and script generation. Handles the heavy lifting of reading dozens of headlines and writing a long-form broadcast.
Fallback model
Claude Sonnet 4.5
Automatically takes over if Gemini fails or hits a rate limit. Both nodes are pre-wired to retry up to 5 times with a 5-second delay between attempts.

Video rendering command (FFmpeg)
# Stitch all audio parts into one file ffmpeg -f concat -safe 0 -i /tmp/list.txt -c copy /tmp/full_audio.mp3 # Render final video: static image + audio → MP4 # scale filter forces even pixel dimensions for H.264 compatibility ffmpeg -loop 1 -i /tmp/background.jpg \ -i /tmp/full_audio.mp3 \ -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2" \ -c:v libx264 -tune stillimage \ -c:a aac -b:a 192k \ -pix_fmt yuv420p \ -shortest /tmp/final_video.mp4
