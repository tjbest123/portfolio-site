Problem it solves

Job searching is manual, slow, and inconsistent

Most job seekers spend hours every week searching multiple job boards, reading postings one by one, and guessing whether a role is a good fit. Important listings go unnoticed. Old postings waste time. There's no systematic way to prioritize where to apply first.

Job Hunter solves this by fully automating the search, evaluation, and logging process - running every Friday night so a curated, AI-scored shortlist is ready first thing Saturday morning.

How it works - step by step
1
Schedule Trigger
The workflow fires automatically every Friday at 10:00 PM. No manual action needed - it runs in the background while you sleep.
n8n Schedule
2
Master Search Config
A configuration node defines 9 job search queries across different categories - from Construction APM to Real Estate PM to Finance PM - each with a set number of pages to scrape. This is the control center of the workflow.
n8n Code Node
3
Google Jobs Scraper (SerpApi)
For each search query, an HTTP request node calls the SerpApi Google Jobs engine with automatic pagination - pulling up to 30 total pages of live job listings from Google's job index.
SerpApi HTTP Request
4
Job Posting Cleanup
Raw API results are normalized into clean, structured records: title, company name, location, salary, full description, apply link, search category, and a unique ID to prevent duplicates.
n8n Code Node
5
AI Technical Recruiter (Claude Sonnet 4.5)
Each job is passed to a Claude AI agent acting as an expert technical recruiter. The agent reads the full job description, compares it against a detailed resume, and scores the role across 4 dimensions using a custom 100-point rubric. It also generates a tailored application strategy for each job.
Claude Sonnet 4.5 LangChain Agent
6
Score Parsing + Freshness Filter
A code node parses the AI's JSON output and applies a 7-day freshness gate - any listing posted more than a week ago is automatically scored 0, preventing time wasted on stale postings.
n8n Code Node Freshness Gate
7
Score Threshold Split
An IF node routes jobs based on fit score. Jobs scoring above 75 are flagged as high-priority. All jobs - regardless of score - are logged to Google Sheets for full visibility.
n8n IF Node
8
Google Sheets Log
Every job is appended to a Google Sheet with full details: date found, title, company, location, fit score, AI reasoning, application strategy, apply link, and status set to "New" for easy follow-up tracking.
Google Sheets

AI scoring rubric (0-100 points)
40 pts
Title & industry alignment
Full points for APM, Project Coordinator, or Operations roles in Real Estate, Construction, or Development. Partial for Finance Ops. Zero for Director/VP roles requiring 7+ years.
30 pts
Automation potential
Awarded for roles mentioning manual reporting, material tracking, vendor coordination, or logistics management - tasks historically improved with technical systems.
20 pts
Tool synergy
Bonus points if the role requires Procore, Yardi, Argus, or advanced Excel financial modeling - matching existing certifications and skills.
10 pts
Graduation fit
Prioritizes roles that value a recent B.B.A. graduate with strong hands-on internship experience over candidates requiring multiple years of full-time experience.
Automatic disqualifiers (score forced to 0)
  • Pure software engineering roles with no operations component
  • Roles requiring specialized licenses (P.E. license, Architecture license, etc.)
  • Strictly administrative roles with no project management responsibilities
  • Job postings older than 7 days (freshness filter)
AI output per job
fit_score
Numeric score from 0-100 based on the rubric above
reasoning
One sentence linking a job duty to specific resume experience
strategy
A tailored pitch or automation idea to use in the application
priority_flag
Boolean - true if fit score exceeds 85. Surfaces top-tier roles instantly
